🛰️ Konfigurasi Sumber Hotspot NASA FIRMS

Melalui proxy aman

Untuk menghindari CORS, dashboard mengambil data melalui Cloudflare Worker. MAP_KEY NASA harus disimpan sebagai Secret bernama FIRMS_MAP_KEY pada Worker, bukan di HTML publik. Masukkan URL Worker setelah Worker dipasang. Tanpa URL proxy, data hotspot tidak dapat dimuat; cuaca dan kualitas udara tetap berfungsi.
